# Day 14 – Full Adder IP Using Half Adder

## 📌 Objective

To design a Full Adder using Half Adder IP blocks and verify the design using AMD Xilinx Vivado.

## 📖 Description

In this project, a Full Adder was designed by combining two Half Adder IP blocks along with the required logic for carry generation. The design demonstrates hierarchical and reusable IP-based digital design in the Vivado environment.

## 🧠 Concepts Learned

* Full Adder
* Half Adder IP
* IP Integration
* Hierarchical Design
* Carry Generation
* Block Design
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tools Used

* AMD Xilinx Vivado
* Vivado IP Catalog

## 📖 What I Learned

* How to use a Half Adder as a reusable IP block.
* How to combine two Half Adders to construct a Full Adder.
* How to connect multiple IP blocks in a Vivado Block Design.
* How to verify the Full Adder functionality.

## ✅ Result

Successfully designed and verified a Full Adder using Half Adder IP blocks in AMD Xilinx Vivado.
