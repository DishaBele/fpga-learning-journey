# Day 11 – Utility Vector and Utility Reduced Logic

## 📌 Objective

To learn and understand the use of Utility Vector and Utility Reduced Logic blocks in AMD Xilinx Vivado for digital logic design and signal manipulation.

## 📖 Description

In this project, Utility Vector Logic and Utility Reduced Logic were explored and used in a Vivado design. These utility blocks help perform logical operations and reduction operations on vector signals, making it easier to process and manipulate multiple-bit signals within a block design.

## 🧠 Concepts Learned

* Utility Vector Logic
* Utility Reduced Logic
* Vector Signal Processing
* Logic Operations
* Reduction Operations
* Block Design
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado

## ✅ Result

Successfully implemented and verified Utility Vector Logic and Utility Reduced Logic blocks in a Vivado Block Design and understood their application in digital logic design.
