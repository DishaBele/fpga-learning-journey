# Day 17 – Adder/Subtractor IP Core in Xilinx Vivado

## 📌 Objective

To learn and implement an Adder/Subtractor IP Core using Xilinx Vivado.

## 📖 Description

Used the Adder/Subtractor IP Core from the Vivado IP Catalog to perform both addition and subtraction operations. The IP was configured and integrated into the design, and its functionality was verified using different input combinations.

## 🧠 Concepts Learned

* Adder/Subtractor IP Core
* Vivado IP Catalog
* IP Configuration
* Addition and Subtraction
* Block Design
* Functional Verification

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Adder/Subtractor IP Core

## 📖 What I Learned

* How to find and configure the Adder/Subtractor IP Core
* How to use the IP for addition and subtraction operations
* How to integrate an IP Core into a Vivado design
* How to verify the output for different input combinations

## ✅ Result

Successfully implemented and verified an Adder/Subtractor IP Core in Xilinx Vivado for performing addition and subtraction operations.
