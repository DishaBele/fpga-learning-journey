# Day 19 – 4-Bit Shift Register Using D Flip-Flops

## 📌 Objective

To implement a 4-bit Shift Register using D Flip-Flops and understand how data is shifted from one stage to the next.

## 📖 Description

Designed a 4-bit Shift Register by connecting four D Flip-Flops in cascade. The design shifts the input data through the flip-flop stages with each clock pulse.

## 🧠 Concepts Learned

* 4-Bit Shift Register
* D Flip-Flop
* Sequential Logic
* Data Shifting
* Clock Signal
* Cascaded Flip-Flops

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Verilog HDL

## 📖 What I Learned

* How D Flip-Flops can be connected to form a shift register
* How data moves between stages on each clock pulse
* The role of the clock signal in sequential circuits
* Implementation of sequential logic using Verilog HDL

## ✅ Result

Successfully implemented a 4-bit Shift Register using D Flip-Flops and verified its data-shifting operation in Xilinx Vivado.
