# Day 07 – Digital Logic Block Design Using Verilog HDL

## 📌 Objective

To design and verify digital logic using Verilog HDL and implement the design using the AMD Xilinx Vivado tool.

## 📖 Description

In this project, digital logic was designed using Verilog HDL and integrated into a block design in Vivado. The design was verified by applying different input combinations and observing the corresponding outputs.

## 🧠 Concepts Learned

* Verilog HDL
* Digital Logic Design
* Block Design
* Module Integration
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado

## ✅ Result

Successfully designed and verified digital logic using Verilog HDL and the Vivado Block Design environment.
