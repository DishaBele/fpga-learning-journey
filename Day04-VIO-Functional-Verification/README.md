# Day 04 – Functional Verification Using VIO

## 📌 Objective

To learn how to use the Virtual Input/Output (VIO) IP in AMD Vivado for real-time functional verification of an FPGA design.

## 📖 Introduction

Virtual Input/Output (VIO) is a Vivado IP core that allows users to monitor internal signals and drive input signals in real time through the Vivado Hardware Manager. It is commonly used for debugging and functional verification without requiring external switches, LEDs, or additional hardware connections.
