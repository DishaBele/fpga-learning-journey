# Day 08 – Block Design and Verification of Combinational Circuit

## 📌 Objective

To design and verify a combinational circuit using the block design environment in AMD Xilinx Vivado.

## 📖 Description

In this project, a combinational circuit was designed using the Vivado Block Design environment. The design was verified by applying different input combinations and observing the corresponding outputs.

## 🧠 Concepts Learned

* Combinational Circuit
* Block Design
* Digital Logic Design
* Functional Verification
* Signal Connectivity
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado

## ✅ Result

Successfully designed and verified a combinational circuit using the Vivado Block Design environment.
