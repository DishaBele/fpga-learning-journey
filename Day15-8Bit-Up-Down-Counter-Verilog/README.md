# Day 15 – 8-Bit Up/Down Counter Using Verilog HDL

## 📌 Objective

To implement an 8-bit Up/Down Counter using Verilog HDL and verify its functionality using AMD Xilinx Vivado.

## 📖 Description

In this project, an 8-bit Up/Down Counter was designed using Verilog HDL. The counter can increment or decrement its value based on the direction control input. The design was simulated and verified in the Vivado environment.

## 🧠 Concepts Learned

* 8-Bit Up/Down Counter
* Verilog HDL
* Sequential Logic
* Clock Signal
* Reset
* Direction Control
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Verilog HDL

## 📖 What I Learned

* How to implement an 8-bit counter using Verilog HDL.
* How to control the counting direction using an Up/Down control signal.
* How clock and reset signals affect sequential logic.
* How to simulate and verify the counter functionality in Vivado.

## ✅ Result

Successfully implemented and verified an 8-bit Up/Down Counter using Verilog HDL in AMD Xilinx Vivado.
