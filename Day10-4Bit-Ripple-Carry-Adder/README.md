# Day 10 – 4-Bit Ripple Carry Adder

## 📌 Objective

To design and understand the working of a 4-bit Ripple Carry Adder using digital logic and verify its functionality using AMD Xilinx Vivado.

## 📖 Description

A 4-bit Ripple Carry Adder is a combinational circuit used to add two 4-bit binary numbers. It is constructed by connecting four 1-bit Full Adders in cascade, where the carry output of each Full Adder is connected to the carry input of the next stage.

## 🧠 Concepts Learned

* 4-Bit Ripple Carry Adder
* Full Adder
* Carry Propagation
* Combinational Circuit
* Block Design
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado

## ✅ Result

Successfully designed and verified a 4-bit Ripple Carry Adder and observed the correct sum and carry outputs using AMD Xilinx Vivado.
