# Day 12 – Up/Down Binary Counter Using IP

## 📌 Objective

To design and verify an Up/Down Binary Counter using an IP core in AMD Xilinx Vivado.

## 📖 Description

In this project, an Up/Down Binary Counter IP was used to implement a counter that can count either upward or downward based on the control input. The design was integrated and verified using the Vivado Block Design environment.

## 🧠 Concepts Learned

* Up Counter
* Down Counter
* Counter IP
* IP Integration
* Block Design
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tools Used

* AMD Xilinx Vivado
* Vivado IP Catalog

## 📖 What I Learned

* How to configure an Up/Down Binary Counter IP.
* How to control the counting direction.
* How to integrate the counter IP into a block design.
* How to verify counter operation in Vivado.

## ✅ Result

Successfully implemented and verified an Up/Down Binary Counter using an IP core in AMD Xilinx Vivado.
