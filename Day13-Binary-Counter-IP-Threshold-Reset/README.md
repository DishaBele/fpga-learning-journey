# Day 13 – Binary Counter IP with Threshold and Reset

## 📌 Objective

To design and verify a Binary Counter using an IP core with threshold detection and reset functionality in AMD Xilinx Vivado.

## 📖 Description

In this project, a Binary Counter IP was configured with threshold and reset functionality. The counter was designed to increment with the clock and respond to the defined threshold condition and reset signal. The design was implemented and verified using the Vivado Block Design environment.

## 🧠 Concepts Learned

* Binary Counter IP
* Threshold Detection
* Reset Functionality
* Counter Configuration
* IP Integration
* Block Design
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tools Used

* AMD Xilinx Vivado
* Vivado IP Catalog

## 📖 What I Learned

* How to configure a Binary Counter IP.
* How to use threshold detection in a counter.
* How reset functionality affects counter operation.
* How to integrate and verify the counter IP in a block design.

## ✅ Result

Successfully implemented and verified a Binary Counter IP with threshold detection and reset functionality using AMD Xilinx Vivado.
