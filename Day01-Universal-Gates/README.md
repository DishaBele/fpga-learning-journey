# Day 01 – Universal Gates (NAND and NOR)

## 📌 Objective

Learn about universal gates and understand how NAND and NOR gates can be used to implement any digital logic circuit.

## 🧠 Topics Covered

* NAND Gate
* NOR Gate
* Why NAND and NOR are called universal gates
* Implementing basic logic functions using universal gates

## 🛠️ Tools Used

* Verilog HDL
* AMD Vivado

## 📂 Files

* `universal_gates.v`

## 📖 What I Learned

* NAND and NOR are universal gates because any logic gate can be constructed using only NAND gates or only NOR gates.
* Implemented NAND and NOR gates in Verilog.
* Simulated the design using Vivado.
* Verified the outputs using simulation waveforms.
