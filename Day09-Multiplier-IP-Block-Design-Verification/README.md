# Day 09 – Verification of Multiplier IP Block Design

## 📌 Objective

To design and verify a multiplier circuit using the Multiplier IP in the AMD Xilinx Vivado Block Design environment.

## 📖 Description

In this project, the Multiplier IP was integrated into a Vivado Block Design. The block diagram was verified by applying different input values and observing the corresponding multiplication output.

## 🧠 Concepts Learned

* Multiplier IP
* Block Design
* IP Integration
* Digital Logic Design
* Functional Verification
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Vivado IP Catalog

## ✅ Result

Successfully integrated and verified the Multiplier IP using the Vivado Block Design environment.
