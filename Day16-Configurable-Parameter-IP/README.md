# Day 16 – Adding a Configurable Parameter to an IP

## 📌 Objective

To learn how to add and use a configurable parameter in an IP using AMD Xilinx Vivado.

## 📖 Description

Implemented a configurable parameter in an IP to make the design flexible and reusable. The parameter allows the IP configuration to be changed according to the required design specifications.

## 🧠 Concepts Learned

* Configurable Parameters
* IP Customization
* Parameterized Design
* IP Integration
* Block Design
* AMD Xilinx Vivado

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Verilog HDL

## 📖 What I Learned

* How configurable parameters are added to an IP
* How parameters can make an IP reusable for different requirements
* How to configure and integrate a parameterized IP in Vivado

## ✅ Result

Successfully added and configured a parameter in an IP and verified its functionality in AMD Xilinx Vivado.
