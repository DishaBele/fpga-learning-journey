# Day 20 – Creating and Packaging a New IP in Vivado

## 📌 Objective

To learn how to create and package a custom IP in AMD Xilinx Vivado for reuse in FPGA designs.

## 📖 Description

Created a new custom IP in Vivado and learned the IP packaging process. The IP was packaged so that it can be added to the Vivado IP Catalog and reused in other FPGA designs.

## 🧠 Concepts Learned

* Custom IP Creation
* IP Packaging
* IP Catalog
* IP Configuration
* IP Integration
* Reusable Design
* Vivado IP Packager

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Verilog HDL

## 📖 What I Learned

* How to create a custom IP in Vivado
* How to package a design as an IP
* How a packaged IP can be added to the IP Catalog
* How reusable IP blocks simplify FPGA design development

## ✅ Result

Successfully created and packaged a custom IP in AMD Xilinx Vivado and learned how to make the IP available for reuse in FPGA designs.
