# Day 03 – 4-Bit Full Adder Design Using Vivado IP Catalog

## 📌 Objective

To design and simulate a 4-bit Full Adder using the AMD Vivado IP Catalog and understand the use of reusable Intellectual Property (IP) cores in FPGA design.

## 📖 Introduction

A 4-bit Full Adder performs the addition of two 4-bit binary numbers along with an optional Carry-in (Cin). It produces a 4-bit Sum and a Carry-out (Cout).

Instead of implementing the complete design in Verilog, this project uses the Vivado IP Catalog to create the adder, demonstrating a faster and more efficient design methodology commonly used in FPGA development.

## 🧠 Concepts Learned

* Introduction to Vivado IP Catalog
* Creating and configuring IP cores
* 4-bit binary addition
* Carry propagation
* RTL design generation
* Functional simulation using Vivado

## 🛠️ Tools Used

* AMD Vivado
* Vivado IP Catalog

## 📂 Project Files

* `design_sources`
* `simulation_files`
* `waveform.png`
* `rtl_schematic.png`

## 📖 What I Learned

* How to create a design using the Vivado IP Catalog.
* How to configure a 4-bit Adder IP.
* How IP cores simplify FPGA development.
* How to generate the RTL schematic.
* How to simulate and verify the design in Vivado.

## ✅ Result

Successfully created, simulated, and verified a 4-bit Full Adder using the AMD Vivado IP Catalog.
