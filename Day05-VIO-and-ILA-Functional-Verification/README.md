# Day 05 – Functional Verification Using VIO and ILA

## 📌 Objective

To learn how to use the Virtual Input/Output (VIO) and Integrated Logic Analyzer (ILA) IP cores in AMD Vivado for real-time functional verification and debugging of FPGA designs.

## 📖 Introduction

VIO and ILA are built-in debugging IP cores provided by AMD Vivado. VIO allows users to drive and monitor internal signals in real time, while ILA captures and displays internal signal activity during FPGA operation. Together, they simplify functional verification and debugging without requiring external hardware connections.
