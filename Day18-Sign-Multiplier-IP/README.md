# Day 18 – Sign Multiplier IP Block

## 📌 Objective

To learn and implement a Sign Multiplier IP Block using Xilinx Vivado.

## 📖 Description

Used the Sign Multiplier IP Block in Xilinx Vivado to perform multiplication operations with signed input values. The IP block was configured and integrated into the design to understand signed multiplication in FPGA-based designs.

## 🧠 Concepts Learned

* Sign Multiplier IP
* Signed Multiplication
* IP Core Configuration
* IP Integration
* Block Design
* Functional Verification

## 🛠️ Tool Used

* AMD Xilinx Vivado
* Sign Multiplier IP

## 📖 What I Learned

* How to use the Sign Multiplier IP Block
* Understanding signed input values in multiplication
* How to configure and integrate the IP block in Vivado
* How to verify multiplication results

## ✅ Result

Successfully implemented and verified a Sign Multiplier IP Block in Xilinx Vivado for signed multiplication operations.
