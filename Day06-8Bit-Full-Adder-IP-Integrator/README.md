# Day 06 – 8-Bit Full Adder Design Using IP Integrator with VIO and ILA Verification

## 📌 Objective

To design an 8-bit Full Adder using the AMD Vivado IP Integrator and perform functional verification using Virtual Input/Output (VIO) and Integrated Logic Analyzer (ILA).

## 📖 Introduction

An 8-bit Full Adder performs the addition of two 8-bit binary numbers along with a Carry-in (Cin). In this project, the design was created using the Vivado IP Integrator. VIO was used to provide input signals during hardware testing, while ILA was used to capture and analyze internal signals for functional verification.
